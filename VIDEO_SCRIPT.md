# Week 1 Video Script (2–5 minutes, ScreenPal)

**0:00 – Intro (20 s)** Introduce yourself and the project: StreamList for EZTechMovie, built with React and React Router.

**0:20 – Project structure (45 s)** In VS Code show: `main.jsx` (BrowserRouter wraps App), `App.jsx` (Routes), `components/Navbar.jsx`, `pages/` (StreamList, Movies, Cart, About), `App.css`.

**1:05 – Navigation (45 s)** In the browser click each menu item. Point out NavLink highlights the active page and the URL changes without a reload.

**1:50 – StreamList input (60 s)** Open DevTools → Console. Type a title, press Add. Show the console log and the item appearing in the list. Explain `useState` for the input and the list, and `preventDefault` in the submit handler.

**2:50 – CSS (40 s)** Show `App.css`: dark theme variables, sticky navbar, gradient active state, hover effects, responsive rule for small screens. Resize the window to demonstrate.

**3:30 – Placeholder pages and wrap-up (30 s)** Show Movies, Cart, About are intentionally empty for Weeks 4–5. Show the GitHub repository URL and close.
