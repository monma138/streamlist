# StreamList – EZTechMovie (Week 1)

React app with React Router navigation: **StreamList** (home), **Movies**, **Cart**, **About**.
The StreamList page takes the user's input and logs it to the browser console.

## Run locally
```bash
npm install
npm run dev
```
Open the URL Vite prints (usually http://localhost:5173) and open DevTools → Console.

## Push to GitHub
```bash
git init
git add .
git commit -m "Week 1: StreamList React app with router and CSS"
git branch -M main
git remote add origin https://github.com/<your-username>/streamlist.git
git push -u origin main
```
